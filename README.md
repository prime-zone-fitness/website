# Prime Zone Fitness Website

A modern, responsive, and high-performance gym website built for **Prime Zone Fitness**, a premium fitness center located in Madhapur, Hyderabad.

The website showcases the gym's services, trainers, facilities, membership plans, transformation programs, and contact information while providing a seamless user experience across desktop, tablet, and mobile devices.

---

## 🚀 Features

* Modern and responsive UI/UX
* Premium fitness-themed design
* Hero section with call-to-action
* About Us section
* Services & Programs
* Membership Plans
* Trainers Showcase
* Facilities & Equipment Gallery
* Testimonials Section
* Contact Form
* Google Maps Integration
* Mobile-Friendly Navigation
* SEO Optimized Structure
* Fast Loading Performance
* Smooth Animations & Transitions

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/your-username/prime-zone-fitness.git
```

Navigate to the project folder:

```bash
cd prime-zone-fitness
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

Preview production build:

```bash
npm run preview
```
